## 🗂️ Project Structure

```
src/
├── config/
│   └── portfolio.config.ts   ← All content lives here (single source of truth)
├── components/
│   ├── Header.tsx
│   ├── Hero.tsx              ← Animated terminal panel
│   ├── About.tsx             ← Code-editor style card
│   ├── ExperienceTimeline.tsx
│   ├── Skills.tsx
│   ├── EngineeringHighlights.tsx
│   ├── Projects.tsx
│   ├── Resume.tsx
│   ├── Contact.tsx
│   ├── Footer.tsx
│   └── icons/
│       └── BrandIcons.tsx    ← GitHub + LinkedIn SVGs
```

> **To update any content** — edit only `src/config/portfolio.config.ts`. Everything else reads from it.
